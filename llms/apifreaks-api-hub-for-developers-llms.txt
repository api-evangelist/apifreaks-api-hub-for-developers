# APIFreaks

> APIFreaks (apifreaks.com) is a first-party REST API platform built by JFreaks Software Solutions (Lahore, Pakistan). It offers 60+ production-ready APIs across IP intelligence, WHOIS, DNS, geocoding, domain tools, email and phone validation, SSL, web scraping, screenshots, PDF processing, currency and commodity data, financial validation, ZIP codes, weather, timezones, GeoDB, user-agent parsing, and astronomy. One API key and one shared credit pool cover every API, and credits are charged only on successful (2xx) responses — 4xx/5xx errors are never billed and any credits already charged are refunded. New accounts get 10,000 free credits with no credit card. APIFreaks is agent-ready: the official @apifreaks/mcp MCP server (Apache-2.0) exposes 57 callable tools across 13 categories to Claude, Cursor, Windsurf, Cline, VS Code, Gemini CLI, and Codex.

## Quick integration

- Site: https://apifreaks.com
- API base: `https://api.apifreaks.com/v1.0/` + endpoint path
- Auth: `X-apiKey: YOUR_KEY` header, or `?apiKey=YOUR_KEY` query parameter
- Methods: GET or POST; JSON by default; XML via `?format=xml` or `Accept: application/xml`
- Billing: credits per call; charged only on 2xx; `X-AF-Credits-Cost` header shows cost
- Free tier: 10,000 credits on signup, no credit card
- Support: support@apifreaks.com — Status: https://status.apifreaks.com/
